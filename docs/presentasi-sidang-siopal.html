BAB II — LANDASAN TEORI

Eloquent Query Filtering & Eager Loading

Query Filtering Eloquent

  • Metode where(), whereHas(), whereBetween()
  • Query Chaining — filter dikombinasikan secara dinamis
  • Binding parameter otomatis — mencegah SQL injection

Sumber: (Akhdani & Wijayanto, 2022)

Eager Loading

  • Metode with() untuk memuat relasi sekaligus
  • Mencegah N+1 Problem — dari ribuan query menjadi konstant
  • Waktu pemrosesan stabil di bawah 200ms

Sumber: (Harahap, 2022) — (Krisna et al., 2024)

Contoh Query Chaining

// 2 Lapisan Filtering

// Layer 1: Database (Eloquent)
$labs = Laboratorium::where('is_active', true)
  ->where('pc_siap', '>=', $count)
  ->whereHas('software', ...)
  ->with(['priorityProdis'])
  ->get();

// Layer 2: Application (Collection)
$slots->filter(fn($slot) => ...)
  ->sortByDesc('priority');

Sequence Diagram: Logika Pencarian Slot

Alur interaksi dari ScheduleWizard ke SchedulingService ke Database:

  1. Admin mengisi formulir & tekan "Cari Slot"
  2. ScheduleWizard memanggil SchedulingService
  3. Filter Lab aktif + kapasitas (DB Layer)

  5. Deteksi konflik slot (DB + App Layer)
  6. Filter sesi, break times, sort prioritas (App Layer)

BAB IV — IMPLEMENTASI

SchedulingService: Algoritma 6 Tahap Filtering

1

Filter Lab Aktif & Kapasitas

Eloquent where('pc_siap', '>=', $count)

2

Filter Software Terinstal

Eloquent whereHas('software') + COUNT

3

Deteksi Konflik Slot Terisi

Query jadwal existing → cek N slot berturutan

4

Filter Sesi Waktu

Collection filter berdasarkan range pagi/siang/malam

5

Eliminasi Jam Istirahat

Overlap detection: start < breakEnd AND end > breakStart

6

Sortir Prioritas Prodi

Lab prioritas di atas, lalu by waktu mulai ascending

Database Layer Application Layer

Constraint statis (kapasitas, software) → DB layer  |  Constraint dinamis (sesi, break, konflik) → App layer
